# Inflow Performance Relationship (IPR) Analysis

### Petroleum Engineering | Production Engineering | Python | Data Analytics

## 📌 Project Overview

This project focuses on the analysis of **Inflow Performance Relationship (IPR)** in petroleum production engineering. IPR describes the relationship between the flowing bottom-hole pressure (Pwf) and the corresponding production rate of a reservoir.

The project uses Python-based data analysis and visualization to study well inflow performance and understand how reservoir pressure conditions influence production potential.

## 🎯 Project Objectives

- Understand the fundamentals of Inflow Performance Relationship (IPR).
- Analyze the relationship between flowing bottom-hole pressure and well production rate.
- Apply Python libraries for petroleum engineering data analysis.
- Visualize production performance through graphical representations.
- Develop insights into well productivity and production optimization.
